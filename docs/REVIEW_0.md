**Title:**
ShareShelf: Student Resource Exchange and Sharing Platform

**Description:**
ShareShelf is a Java-based student resource-sharing web application designed to help college students at Galgotias University exchange, borrow, donate, and discover useful academic items. Students create resource listings, search and filter available items, send requests, and manage listing status through a full lifecycle (Available → Reserved → Borrowed/Exchanged → Closed). The system supports categories such as academic materials, lab equipment, stationery, event supplies, and electronics, through borrow, exchange, donation, and giveaway listing types. The project uses a Java Servlet backend with JDBC-based MySQL persistence, an HTML/CSS frontend, object-oriented design across model and DAO layers, multithreading for automated overdue-request detection, and transaction management for multi-step database operations such as request acceptance. A privacy-respecting trust mechanism (WhatsApp contact reveal, scoped strictly to overdue transactions) supports safe, campus-level coordination between students without live location tracking or in-app chat.
